# Principles for IE OS

## 1. Identity Engineering first

Every operational contract must be derivable from or consistent with the core primitives:

- Mass (relative, perceived, interaction-depth-weighted)
- Curvature, Gravitation, Rotation, Frequency, Relativity
- Identity Stem (State Differential + Vision Gradient)
- Causal Entropic Forces
- Questions as Probes (continuous process that turns Interaction into relative geometry)
- Ownership as relative degrees of freedom / Jurisdiction over the Stem

No pattern is imported just because it worked in an earlier product. Patterns enter only when Framework-grounded.

## 2. Static files + Dynamic entry + Living Tension Tensor

- Static layer = relative perception an Identity holds of itself and others.  
- Local entry = always-on entry point for State Differential + Vision Gradient + tension signals.  
- Every interaction updates geometry (Geometry Receipt) and can write back into static files.

This turns dead documents into living identity artifacts.

## 3. Relative and local by default

- Mass, Registry, and most signals are relative to the observing Identity.  
- Registry is local. Global IDs are not required.  
- Minimal always-shareable signal: existence + interaction depth (+ optional coarse Mass).  
- Richer signals are consent-based.  
- Sensing is bidirectional with agency on both sides (outbound signals + inbound estimate requests; never auto-answered).

## 4. Privacy, Consent, Refusal-of-Control

Structural defaults against surveillance, forced alignment, and over-transparency.  
Encoded in Stem, local entry, Mass ratings, Registry, and Surface policy.

## 5. Multi-substrate symmetry from day 1

Same Stem / Trajectory / Surface contracts for human Identities and substrate-free / Physical AI runtimes without undermining human agency.

## 6. Practical installability

Clonable / copyable so that "IE is installed" and the next interaction already lives via local entry + Geometry Receipt + Tension update.  
CLI free personal / paid collective tiers later — after core contracts are solid.

## 7. Living form in, organism agents out

**In:**

- Think · Interact · Mature as Probe phases under Relativity (`docs/tim-cycle.md`)  
- Living-form lens: Identity as operative form with membrane (Surface) and metabolism (Interaction → Geometry Receipt) (`docs/living-form.md`)  
- Explicit split: Identity ≠ agentic loop (loop may be nuclear machinery inside the form)

**Out (for now):**

- Biology-inspired *agents* (sensory, immunity, vitality, creativity, stability) and full Dynamic Governance until derivable from Surface, Geometry Receipt, Ownership, Emergence, and Damping without category error.

## 8. Standard first, platform optional

Open Identity-Geometry standard + local-first runtime. Collective-intelligence ecosystem may grow on the contracts; a global social/attention platform is not the v0 goal.

## 9. Python for core and CLI (v0–v1)

Surface Runtime and `ie` CLI are Python (Typer). Schemas stay language-neutral. Optional agents consume IE via CLI/Surface/contracts — they are not the kernel.
