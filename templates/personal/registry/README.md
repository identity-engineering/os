# Local Registry (personal)

This folder is the observing Identity's **local gravitational sensor**.

- One file per recognized Identity: `{local_handle}.yaml`
- Owned by the observing Identity
- Relative, static from the outside, privacy-defaults structural
- Relation is first-class (Relativity)
- No global IDs required

See `schemas/registry/v0.yaml` for the full contract and `docs/registry.md` for the reasoning.
