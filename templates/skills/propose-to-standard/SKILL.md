# Propose to standard

## Purpose

Local Mature improves **this** Identity. Collective intelligence requires a path back into the shared standard (`identity-engineering/os`, public `identity-engineering/framework`).

## When invoked

1. Summarize the learning with the human (what broke, what was missing, proposed contract change).
2. Prefer opening a **GitHub issue** on `identity-engineering/os` (operational) or `identity-engineering/framework` (public concept) with:
   - Title: short, specific
   - Body: context, observed gap, proposed change, link to local Mature notes if shareable
   - Labels if known: `priority:*`, related issue numbers
3. Do not push or merge to `main` without explicit human approval.
4. Optionally record locally that feedback was filed (workspace note / evidence file) via `ie mature` if the human wants the loop closed on their Identity.

## Rules

- This skill does not auto-update remote repos.
- Inbound absorption of standard changes into local installs is a separate evolve path (see issue on central standard evolve).
